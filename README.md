## 📝 프로젝트 소개

> **로또 발매기**
> 사용자가 입력한 금액만큼 로또 번호를 발행하고, 당첨 번호를 통해 당첨 결과와 수익률을 계산하는 프로그램입니다.

* **언어**: Java 21
* **빌드 도구**: Gradle
* **사용 라이브러리**: `camp.nextstep.edu.missionutils`
* **주요 기능**
    * 로또 번호 자동 발행
    * 당첨 번호 입력 및 결과 계산
    * 수익률 계산 및 출력

---

## 📍기능 목록

- **로또 구입**
    * [x] 사용자로부터 구입 금액을 입력받는다.
    * [x] 입력한 금액만큼 중복되지 않는 1~45 범위의 6개 숫자가 적힌 로또를 발행한다. (1장 = 1,000원)
    * [x] 발행한 로또 번호를 오름차순으로 정렬하여 출력한다.
    * [x] [예외] 1,000원 단위가 아닌 경우 예외 처리한다.

- **당첨 번호 입력**
    * [x] 사용자로부터 당첨 번호 6개를 입력받는다. (쉼표 구분)
    * [x] 사용자로부터 보너스 번호 1개를 입력받는다.
    * [x] [예외] 당첨 번호 및 보너스 번호에 중복이 있는 경우 예외 처리한다.
    * [x] [예외] 1~45 범위를 벗어난 경우 예외 처리한다.

- **당첨 결과 계산**
    * [x] 구입한 로또 번호와 당첨 번호를 비교한다.
    * [x] 다음 기준에 따라 순위를 판단한다.
        - 6개 일치 → 1등
        - 5개 + 보너스 번호 일치 → 2등
        - 5개만 일치 → 3등
        - 4개 일치 → 4등
        - 3개 일치 → 5등
    * [x] 당첨금 기준 오름차순으로 당첨 통계를 출력한다.

- **수익률 계산**
    * [ ] 총 당첨 금액을 계산한다.
    * [ ] 수익률을 계산하고 소수점 둘째 자리에서 반올림하여 출력한다.

- **예외 처리**
    * [ ] [ERROR]로 시작하는 메시지를 출력한다.
    * [ ] 예외 발생 시 해당 입력 단계부터 다시 입력받는다.

## 📍테스트 코드 목록

- **로또 구매 단위 테스트**
    - **성공 케이스**
        * [x] 1,000원으로 1개의 로또를 발행한다.
        * [x] 11,000원으로 11개의 로또를 발행한다.
        * [x] 발행된 각 로또는 6개의 번호를 가진다.
    - **실패 케이스**
        * [x] 1,000원 단위가 아닌 경우 예외가 발생한다. (2,500원)
        * [x] 최소 금액보다 작은 경우 예외가 발생한다. (500원)
        * [x] 최대 금액보다 큰 경우 예외가 발생한다. (100,009,000원)
        * [ ] 예외가 발생하면 `[ERROR]` 메시지 출력 후 재입력 받는다.

- **당첨 번호 입력 단위 테스트**
    - **성공 케이스**
        * [x] 정상적인 당첨 번호와 보너스 번호를 입력하면 객체가 생성된다.
    - **실패 케이스**
        * [x] 당첨 번호의 개수가 6개가 아니면 예외가 발생한다.
        * [x] 로또 당첨 번호와 보너스 번호에 중복된 숫자가 있으면 예외가 발생한다.
        * [x] 번호가 1~45 범위를 벗어나면 예외가 발생한다.
        * [ ] 예외가 발생하면 `[ERROR]` 메시지 출력 후 재입력 받는다.

- **당첨 결과 계산 단위 테스트**
    - **성공 케이스**
        * [ ] 구입한 로또가 당첨 번호 6개와 모두 일치하면 1등으로 판단된다.
        * [ ] 구입한 로또가 당첨 번호 5개 + 보너스 번호와 일치하면 2등으로 판단된다.
    - **실패 케이스**
        * [ ] 추가 예정

- **수익률 계산 단위 테스트**
    - **성공 케이스**
        * [ ] 수익률이 소수점 둘째 자리에서 반올림되어 출력된다.
    - **실패 케이스**
        * [ ] 추가 예정

- **통합 테스트**
    - **성공 케이스**
        * [ ] 추가 예정
    - **실패 케이스**
        * [ ] 숫자가 아닌 입력에 대해 예외가 발생한다.
